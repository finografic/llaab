Linking Notes Together

A stored article that keeps relative links is a stored article that will eventually resolve against the wrong origin. Rewriting them at parse time is cheaper than repairing them later, and it makes the persisted Markdown independently useful — see the identifier reference, the glossary, and the nested note for the vocabulary this piece assumes.

Protocol-relative sources deserve the same treatment. An that silently follows the page protocol is a small inconsistency on the live page and a broken reference in an archive. Resolve everything against the final response URL, once, at the boundary, and the rest of the system can treat the stored document as self-contained.

Anchors that point only at a fragment, like footnotes, should stay relative because they refer to the document itself rather than to another resource.
